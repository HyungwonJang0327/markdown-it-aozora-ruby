# Justdown 통합 — ⏸ 미결

- **상태**: 미결. v1.0.0 배포 범위에 포함하지 않는다.
- **맥락**: 원래 계획에는 "Justdown이 이 패키지를 의존성으로 사용하도록 교체"가 있었으나, 사용자 판단으로 별도 검증이 필요해 보류. Justdown은 Expo(React Native) 앱이라 Metro 번들러와 dual 패키지의 호환성, WebView 렌더링 결과 동일성 검증이 선행되어야 한다.
- **재검토 조건**: v1.0.0 배포 완료 후, Justdown에서 devDependency로 설치해 기존 마크다운 테스트 스냅샷이 동일하게 나오는지 확인한 뒤 결정한다.
- **결정일**: 2026-09-06 (보류 결정)
